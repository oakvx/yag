SERVER CONFIGURATION

Connect to YAG

Enter the HTTPS address of your YAG Host and a client API key issued by its administrator. Your key stays in memory and is never saved to disk.

Use the HTTPS LAN endpoint. For local development only: http://127.0.0.1:8080
Install the host's trusted root CA on this computer. Certificate verification is never bypassed.
CLIENT SETTINGS

Preferences

When enabled, conversation text is saved in this application's WebView storage without encryption. No API key is saved. Disabling history immediately deletes it from local storage.

Local API relay

Expose the connected YAG models as a local OpenAI-compatible API on 127.0.0.1 only. A separate temporary token is required, including for local programs.
