YAG optional original media

The interface uses a neutral sans-serif stack and project-drawn glyphs.
Boot, navigation, trophy and ambient sounds use original procedural synthesis.
Optional replacements must be original or appropriately licensed for deployment.

Wordmark:
  public/fonts/PS4-Logo.otf
  public/fonts/YAG-Boot-Display.woff2
  public/fonts/YAG-Boot-Display.ttf

Audio:
  public/audio/start.mp3
  public/audio/yag-home.mp3 (or .ogg; optional ambient track)
  public/audio/cursor.mp3
  public/audio/select.mp3
  public/audio/cancel.mp3
  public/audio/trophy.mp3

Trophy artwork:
  public/icons/trophies/bronze.png
  public/icons/trophies/silver.png
  public/icons/trophies/gold.png
  public/icons/trophies/platinum.png

The optional PS4-Logo font is used for the YAG wordmark when present and is
included in production builds. Deploy it only where you have the required rights.
Other legacy font and sample filenames are not loaded or copied into production.
Existing user files are left intact on disk.
The built-in icon set is credited in third_party/xmb-icons.
The supplied esseti PS3 SVG overrides in public/icons/xmb are documented in
third_party/xmb-icons-esseti/NOTICE.md; they are separate from that MIT pack.
